# ✈️ Sky Ace: Dogfight Arena (Multiplayer Online)

เกมดวลเครื่องบินรบ **Dogfight ออนไลน์กับเพื่อนได้สูงสุด 10 คน**
เล่นออนไลน์ได้แม้เพื่อนจะ **ไม่ได้อยู่ด้วยกัน ไม่ได้ใช้อินเทอร์เน็ตบ้านเดียวกัน** เข้าเล่นได้จากทั่วโลก!

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/1stO-coder/dogfight)

## 🌐 วิธีเปิดเล่นกับเพื่อนที่ไม่ได้อยู่ด้วยกัน (Play with Friends Anywhere)

### วิธีที่ 1: คลิกเดียวเล่นได้ทันที (Instant Global Online Tunnel) ⭐ แนะนำ
คุณไม่ต้องสมัครสมาชิก ไม่ต้องตั้งค่า Forward Port ในเร้าเตอร์ ระบบมี **Cloudflare Tunnel** ติดตั้งไว้ในตัวเรียบร้อยแล้ว:

1. เปิด Terminal ในโฟลเดอร์นี้ แล้วรันคำสั่ง:
   ```bash
   ./start_dogfight.sh
   ```
2. รอประมาณ 3–5 วินาที หน้าจอจะแสดงลิงก์ออนไลน์ระดับโลกขึ้นมา เช่น:
   ```
   ======================================================================
    🎉 สร้างลิงก์ออนไลน์สำหรับเล่นกับเพื่อนสำเร็จแล้ว! (Online Ready)
   ======================================================================

    🌐 ส่งลิงก์นี้ให้เพื่อนเข้าเล่นได้ทันที (เล่นได้จากทุกที่ทั่วโลก):
       👉 https://nights-missile-surgeon-examples.trycloudflare.com

    💻 สำหรับคุณเล่นในเครื่องนี้:
       👉 http://localhost:8088
   ```
3. **ส่งลิงก์สีฟ้าให้เพื่อนใน LINE, Discord, Messenger หรือแชท:**
   - เพื่อนเปิดลิงก์ผ่านเว็บเบราว์เซอร์บนคอมพิวเตอร์, แท็บเล็ต, หรือมือถือ
   - ตั้งชื่อ Callsign และใส่ **รหัสห้องเดียวกัน** (เช่น `SKY-1`)
   - ทั้งคุณและเพื่อนจะเจอกันบนน่านฟ้าและบินไล่ยิงกันได้ทันทีแบบ Real-time!
4. เมื่อเล่นเสร็จแล้ว กด `Ctrl + C` ใน Terminal เพื่อปิดเซิร์ฟเวอร์

### วิธีที่ 2: ขึ้น Cloud ให้เพื่อนเล่นได้ตลอด 24 ชม. (Free 24/7 Hosting on Render)
หากคุณไม่อยากเปิดคอมพิวเตอร์ทิ้งไว้ สามารถนำโฟลเดอร์นี้ขึ้น **Render.com** (ฟรี 100%) เพื่อให้มีลิงก์ถาวร:

1. สมัครใช้งานฟรีที่ [Render.com](https://render.com/)
2. สร้าง **New Web Service** จาก GitHub Repository ของคุณ
3. ในช่อง **Build Command**: ใส่ `pip install -r requirements.txt`
4. ในช่อง **Start Command**: ใส่ `python server.py`
5. คุณจะได้ลิงก์ถาวร เช่น `https://sky-ace-dogfight.onrender.com` ให้เพื่อนเข้ามาเล่นได้ตลอด 24 ชั่วโมง

## 🕹️ การควบคุมเครื่องบิน (Flight Controls)

| หน้าที่ | จอยสติ๊กการบิน (Flight Joystick / HOTAS) | คีย์บอร์ด / เมาส์ (Keyboard) |
|---|---|---|
| **Pitch (เชิด/กดหัวเครื่อง)** | • **ดึงคันโยกถอยหลัง (Pull Back):** หัวเชิดขึ้น (Climb)<br>• **ดันคันโยกไปข้างหน้า (Push Forward):** หัวกดลง (Dive) | • **ปุ่ม S:** หัวเชิดขึ้น (Climb)<br>• **ปุ่ม W:** หัวกดลง (Dive) |
| **Bank / Roll (เลี้ยวเอียงปีก)** | • **โยกซ้าย:** เลี้ยวเอียงปีกซ้าย<br>• **โยกขวา:** เลี้ยวเอียงปีกขวา | • **ปุ่ม A:** เอียงปีกซ้าย<br>• **ปุ่ม D:** เอียงปีกขวา |
| **Throttle (ความเร็วเครื่องยนต์)** | • แกน Throttle บนจอยสติ๊ก | • **Shift** หรือ **ลูกศรขึ้น:** เร่งเครื่อง (Afterburner สูงสุด 140 kts)<br>• **Ctrl** หรือ **ลูกศรลง:** ผ่อนเครื่อง (แอร์เบรก ต่ำสุด 70 kts) |
| **Cannon Fire (ยิงปืนกลอากาศ)** | • **ไกปืน Trigger (Button 0)** / RT / RB | • **Spacebar** หรือ **คลิกเมาส์ซ้าย** |
| **Leaderboard (ตารางคะแนน)** | • ปุ่ม Select / Back บนจอย | • **กดปุ่ม Tab ค้างไว้** |

## 🏆 กติกาการรบและการบิน (Combat & Aerobatics Rules)

1. **พลังชีวิตและเลเวล (Hull & Level):** 
   - ผู้เล่นทุกคนเริ่มที่ 100 HP (LV.1)
   - ยิงศัตรูตก 1 ลำ: เลเวลอัป เพิ่ม HP สูงสุด +15 และฮีลเลือดทันที +40 HP
   - เมื่อตาย: เลเวลจะรีเซ็ตกลับมาเป็น LV.1
2. **การบินและท่าตีลังกา (Loop-the-Loop & Energy Dynamics):**
   - **เชิดหัวทำท่าตีลังกา (Vertical 360° Loop):** ดึงคันบังคับหรือกด **S** ค้างไว้เพื่อเชิดหัวขึ้นทำท่าตีลังกาเต็มวง 360 องศา ชมวิวท้องฟ้าและผืนดินกลับหัวแบบสมจริง
   - **ฟิสิกส์ความเร็วตามมุมบิน:** เชิดหัวขึ้น (Climb) แรงโน้มถ่วงจะดึงให้ความเร็วลดลง (~45-65 kts), กดหัวดิ่งลง (Dive) แรงโน้มถ่วงจะช่วยเร่งความเร็วพุ่งทะยาน (~140-165 kts)
3. **ระบบเล็งยิงปืนกลอากาศ (Manual Gunsight < 500m):**
   - ยกเลิกระบบล็อกเป้าอัตโนมัติ (No Lock-on) เน้นฝีมือการเล็งแบบ Dogfight คลาสสิก
   - **ระยะยิงหวังผล:** สามารถยิงโดนเป้าหมายได้เฉพาะที่ **ระยะน้อยกว่า 500 เมตร (< 500m)** เท่านั้น เกิน 500m จะไม่สามารถยิงโดน
4. **ไอเทมในน่านฟ้า (Tactical Pickups):**
   - มีกล่องไอเทมสุ่มเกิดทั่วแผนที่ (แสดงสัญลักษณ์บนเรดาร์): กล่องพยาบาล (+50 HP), ปืนแรง (2x Damage), และเกราะพลังงาน (+20 Temporary HP Armor) นาน 2 นาที
5. **การเกิดใหม่ (Respawn & Safe Spawn):**
   - เกิดใหม่ในตำแหน่งสุ่มปลอดภัยทั่วทั้งแผนที่ พร้อมเกราะป้องกันการเกิด 3 วินาที (Spawn Protection)
